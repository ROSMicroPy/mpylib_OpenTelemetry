Continue an incoming HTTP trace

extract_traceparent() returns a dictionary, not a SpanContext. Convert it before passing it to a tracer. The helper looks for the lowercase traceparent key.

from otel import SpanContext, extract_traceparent, get_tracer

headers = {
    "traceparent": "00-4bf92f3577b34da6a3ce929d0e0e4736-00f067aa0ba902b7-01"
}
parts = extract_traceparent(headers)
parent = None
if parts:
    parent = SpanContext(
        trace_id=parts["trace_id"],
        span_id=parts["span_id"],
        trace_flags=parts["trace_flags"],
        is_remote=True,
    )

tracer = get_tracer("receiver")
with tracer.start_as_current_span("command.receive", parent_context=parent):
    pass

Validate at the boundary. Extraction only checks the number of hyphen-separated parts. It does not validate hexadecimal lengths, nonzero IDs, version, or flags. SpanContext.is_valid() checks only that IDs are nonempty. Normalize and validate incoming headers before trusting them in production.

Inject an outgoing header

from otel import inject_traceparent, get_tracer

tracer = get_tracer("sender")
with tracer.start_as_current_span("command.send") as span:
    headers = {"Content-Type": "application/json"}
    if span.context is not None:
        inject_traceparent(headers, span=span)
    # Pass headers to your HTTP client's request.

Injection mutates and returns the header dictionary. When no context exists it leaves the dictionary unchanged. Passing a no-op span explicitly can produce invalid identifiers, so guard it as above. The implementation does not include baggage or tracestate.

Carry context in a message

For JSON messages, use the nested otel carrier field. Choose a different field value if that name conflicts with your payload.

from otel import (
    attach_span_context, extract_from_carrier,
    get_tracer, inject_to_carrier,
)

tracer = get_tracer("messages")
with tracer.start_as_current_span("command.publish"):
    message = {"command": "move"}
    inject_to_carrier(message)

# On the receiving device, after decoding the message:
parent = extract_from_carrier(message)
with attach_span_context(parent):
    with tracer.start_as_current_span("command.consume"):
        pass

The carrier contains trace_id, span_id, and trace_flags. Extraction returns a remote SpanContext or None if required fields are absent.

Context is global

The current span lives in one module-level variable. It is neither thread-local nor task-local. Avoid interleaving active span scopes across threads or asynchronous tasks. Pass explicit parent contexts where useful, but do not assume that doing so isolates the global context used by log correlation.

New span contexts use the default 01 flags; remote flags are not implemented as a sampling policy. Treat these helpers as basic correlation utilities rather than a full W3C validation and sampling implementation.
