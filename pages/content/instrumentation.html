The following patterns assume a successful setup. Keep names stable, choose low-cardinality attributes, and create instruments once.

Trace a unit of work

from otel import get_tracer

tracer = get_tracer("controller")
with tracer.start_as_current_span("command.execute") as command:
    command.set_attribute("command.type", "move")
    with tracer.start_as_current_span("motor.update") as motor:
        motor.add_event("target accepted", {"position": 120})
        motor.set_status("OK")
    command.set_status("OK")

Entering a span makes it current. Nested spans inherit its trace ID and use its span ID as their parent. Leaving the block ends the span and restores the previous context. An escaping exception is recorded as an event and sets status to ERROR; it still propagates to your application.

start_span() returns a span without making it current. Call end() yourself or use it in a with block. Calling end() again has no effect on an already-ended real span. Use status strings UNSET, OK, or ERROR.

Correlate structured logs

from otel import get_logger, get_tracer

logger = get_logger("controller")
tracer = get_tracer("controller")
with tracer.start_as_current_span("command.validate"):
    logger.info("received command", {"command.type": "move"})
    logger.warn("battery low", {"battery.percent": 15})

Messages support debug, info, warn/warning, and error. Logs inside a current span include its identifiers. logger.emit(severity_text, body, attributes=None, span=None) lets you specify an explicit span.

Real logger methods accept force=True to bypass the severity filter, but no-op loggers do not accept that keyword. Avoid passing it in code that may use a no-op logger. An emitted real log returns a LogRecord; filtered or disabled calls can return True. The return value is not a delivery receipt.

Choose an instrument

Counteradd(amount, attributes=None)Cumulative nonnegative counts, such as samples. Negative values are not rejected by code; keep updates nonnegative.

Gaugeset(value, attributes=None)The latest measurement for each attribute set, such as temperature.

from otel import get_meter

meter = get_meter("controller")
commands = meter.create_counter("commands.total", unit="1")
active = meter.create_up_down_counter("commands.active", unit="1")
voltage = meter.create_gauge("battery.voltage", unit="V")
duration = meter.create_histogram("command.duration", unit="ms")

commands.add(1, {"command.type": "move"})
active.add(1)
voltage.set(12.1)
duration.record(42.0, {"command.type": "move"})
active.add(-1)

Each distinct attribute combination creates a retained point. Use small, stable scalar values; lists and dictionaries cannot be used in the metric point key. Avoid timestamps, request IDs, or ever-changing values as metric attributes. Counter and histogram values remain cumulative across collection; gauges retain their last value.

Collection is explicit. Call the returned reader's collect() to send data. Calling meter_provider.collect() only returns snapshots. Enabling async export does not schedule or move metric export to a background thread.

Instrument an outgoing HTTP call

from otel import get_tracer, traced_request

tracer = get_tracer("network")
response = traced_request(
    tracer, "GET", "http://192.168.1.100:8080/health", timeout_s=3
)
try:
    print(getattr(response, "status_code", None))
finally:
    response.close()

The helper creates an HTTP GET span, adds method/URL/status attributes, and injects traceparent. You own and must close the response. The span covers the request call, not later response processing. HTTP error statuses are attributes; they are not automatically mapped to an error span status.

If an HTTP span is suppressed or telemetry is disabled, the current helper can inject an invalid no-op context. Applications needing strict propagation should guard this helper with should_emit_span() and use their HTTP client directly when the span would be suppressed.
